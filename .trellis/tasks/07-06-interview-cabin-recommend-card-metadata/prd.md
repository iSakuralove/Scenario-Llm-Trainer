# 面试舱推荐卡信息密度补齐 PRD

## 目标

补齐推荐训练卡片里仍未显式展示的信息，让用户在不点开轨道详情的前提下，直接看到：

- 适合对象
- 预计耗时
- 题库状态

本任务只增强 `InterviewsPage` 推荐卡展示，不新增接口。

## 已确认事实

- 推荐卡当前已经有：
  - 推荐原因
  - 领域 / 难度 / 题型
  - 开始训练 / 查看覆盖
- 前端设计文档明确要求推荐卡包含：
  - 适合对象
  - 预计耗时
  - 题库状态
- 这些信息都可以由现有前端数据推导：
  - `difficulty` -> 适合对象
  - `questionType` + `difficulty` -> 预计耗时
  - `availabilityState` / `vectorStatusSummary` -> 题库状态

## 需求

1. 推荐卡元信息
   - 显式展示“适合对象”
   - 显式展示“预计耗时”
   - 显式展示“题库状态”

2. 实现约束
   - 优先复用现有 `interviewLevels`、`launchTrackAvailabilityLabel`、`launchpadVectorStatusLabel` 等映射。
   - 不新增后端字段。

## 验收标准

- 推荐卡可直接看到适合对象、预计耗时和题库状态文案。
- 不影响现有推荐卡主次按钮与主体点击行为。

## 不做

- 不新增独立详情页。
- 不新增真实计时器或服务端耗时统计。
