# 面试舱推荐卡开始训练按钮 PRD

## 目标

把面试舱推荐卡补成完整的“双动作”结构：

- 主按钮：开始训练
- 次按钮：查看覆盖

本任务只增强 `InterviewsPage` 推荐卡交互，不新增接口、不修改后端推荐逻辑。

## 已确认事实

- 当前推荐卡已经有：
  - 主体内容点击后只选中轨道
  - 次按钮 `查看覆盖`
- 页面已有统一的 `start()` 启动逻辑，会使用当前选中轨道和页面上的准备参数创建会话。
- 前端设计文档要求推荐卡应具备主按钮“开始训练”和次按钮“查看覆盖”。

## 需求

1. 推荐卡主按钮
   - 每张推荐卡显示显式主按钮 `开始训练`。
   - 点击后应直接复用当前页面 `start()` 流程启动面试。
   - 启动前要确保当前轨道被切换到该推荐项对应轨道。

2. 兼容现有交互
   - 仍保留点击推荐卡主体内容时只选中轨道的轻量交互。
   - 不影响已有 `查看覆盖` 次按钮。
   - 不影响页面顶部和开放轨道区的“开始面试”按钮。

3. 状态
   - 当页面正在启动面试时，推荐卡主按钮也应进入禁用态，避免重复创建会话。

## 验收标准

- 推荐卡存在显式 `开始训练` 主按钮。
- 点击该按钮会进入会话创建流程，而不是仅仅选中轨道。
- 页面启动中时，推荐卡主按钮不可重复点击。

## 不做

- 不新增后端字段。
- 不改推荐来源算法。
- 不新增独立推荐详情页。
