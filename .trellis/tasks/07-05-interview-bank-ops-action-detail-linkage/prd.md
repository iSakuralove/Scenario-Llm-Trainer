# 面试题库运营动作详情联动现有治理入口 PRD

## 目标

在已有运营动作 open 队列、候选预览和候选保存基础上，补齐下一个治理切片：管理员可以打开运营动作详情，看到触发证据和当前关联原子上下文，并从详情直接复用现有题库治理入口，而不是再手工搜索。

本切片只做“动作详情 + 原子当前状态联动 + 现有入口跳转/重建联动”，不提前实现动作状态流转、关闭备注、重开或动作历史表。

## 用户价值

- 管理员能直接理解某个运营动作为什么存在，而不是只看到队列标题。
- 管理员能看到关联 atom 当前是否仍存在、是否已归档、当前版本是多少、索引状态是什么，从而判断动作是否已经过时。
- 管理员可以从动作详情直接进入已有原子详情、健康诊断/检索预览筛选和索引重建入口，减少面板之间来回切换。

## 已确认事实

- `GET /api/v1/admin/interview-bank/ops-actions` 已能返回 open 动作列表。
- 前端 `InterviewBankAdminPage` 已支持：
  - `handleOpenAtom` 打开题库原子详情和版本历史；
  - `applyOpsActionTarget` 把动作组合目标套用到题库筛选和检索预览；
  - `handleRebuild` 走现有索引重建 API。
- 当前没有运营动作详情接口，也没有动作详情面板。
- 现有动作数据仅持久化在 `interview_bank_ops_actions` 主表中，没有状态历史表。

## 需求

1. 新增管理员动作详情接口：
   - `GET /api/v1/admin/interview-bank/ops-actions/{id}`
   - 只允许管理员调用。
   - 返回动作本身、轻量关联原子上下文和是否 stale 的判断结果。

2. 关联原子上下文规则：
   - 当动作有 `atom_id` 且 atom 存在时，返回当前 atom 的轻量信息：
     - `id`
     - `title`
     - `status`
     - `vector_status`
     - `current_version`
     - `updated_at`
   - 当动作 `atom_id` 不存在对应 atom 时，标记 `stale=true`，原因是“关联 atom 不存在”。
   - 当动作关联 atom 当前已归档时，标记 `stale=true`，原因是“关联 atom 已归档”。
   - 当动作没有 `atom_id` 时，不返回 atom 上下文，也不强行标记 stale。

3. 动作详情展示：
   - 展示动作标题、类型、状态、优先级、来源、更新时间、原因。
   - 展示 compact evidence，不展开完整用户内容，不新增额外敏感字段。
   - 对组合目标显示 domain/category/difficulty。
   - 对 atom 目标显示 atom 当前状态、版本和索引状态。

4. 现有治理入口复用：
   - 对有组合目标的动作，详情中可继续“套用到题库筛选/检索预览”。
   - 对有 `atom_id` 的动作，详情中可继续“打开原子详情”。
   - 对 `action_type=rebuild_index` 且存在关联 atom 的动作，详情中可直接走现有单 atom 索引重建路径。
   - 不新增新的重建 API，不绕过现有 admin 重建边界。

5. 边界和不做
   - 不做 `PATCH /ops-actions/{id}`。
   - 不新增动作历史表或状态流转历史。
   - 不自动 resolve/dismiss/reopen。
   - 不自动修改 atom、归档资源或自动触发组合级修复。
   - 不改变候选生成/保存语义。

## 验收标准

- 管理员请求动作详情时，能拿到动作本身与 compact evidence。
- 当动作关联有效 atom 时，详情返回当前 atom 的 `status/vector_status/current_version`。
- 当动作关联 atom 已被归档或不存在时，详情返回 `stale=true` 和明确原因。
- 前端可以从动作详情打开现有 atom 详情。
- 前端可以从动作详情继续套用组合目标到现有筛选/检索预览。
- `rebuild_index` 类 atom 动作可以从详情直接触发一次现有单 atom 重建流程。
- 非管理员访问动作详情返回现有权限错误。

## 风险与约束

- 本切片不能提前引入状态流转，否则会和后续“关闭、忽略、观察、重开闭环”切片重叠。
- 详情接口应返回轻量 atom 上下文，避免把完整 atom 正文重复塞进运营动作详情响应。
- 组合级 `rebuild_index` 动作没有单一 atom 目标，本切片不为其发明新的“批量自动重建”语义。

## 不做

- 不做动作状态切换。
- 不做动作备注历史。
- 不做组合级一键批量重建。
- 不做自动关闭 stale 动作。
- 不做浏览器冒烟自动化。
