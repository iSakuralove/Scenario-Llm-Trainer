# 面试舱目标画像与档案提示 PRD

## 目标

补齐面试舱准备页里与“个人档案”相关的显式展示，让用户在开始面试前能看到系统当前会参考的目标画像，并在缺少简历/项目摘要时看到中性提示。

本任务只增强 `InterviewsPage` 的准备信息展示，不新增后端字段。

## 已确认事实

- 用户资料已存在：
  - `target_level`
  - `preferred_domains`
  - `resume_summary`
  - `project_summary`
- 当前页面只把简历/项目摘要拼进“准备备注”的默认值，用户不容易感知系统到底读到了什么。
- PRD 已确认：
  - 准备页要补充目标岗位 / 难度倾向 / 重点能力 / 个人档案上下文
  - 如果没有简历摘要/项目经历摘要，只能给中性提示“补充后更精准”，不能警告或阻断

## 需求

1. 目标画像展示
   - 在准备区显式展示：
     - 目标职级
     - 偏好领域
   - 不新增编辑入口，只展示当前已保存档案。

2. 档案上下文提示
   - 当存在简历摘要或项目摘要时，提示当前会参考这些内容。
   - 当两者都为空时，显示中性提示：
     - 类似“补充个人档案后，本场追问会更精准”
   - 不允许把该状态呈现成错误、警告或阻断。

3. 兼容性
   - 不影响现有准备备注编辑。
   - 不影响开始面试流程。

## 验收标准

- 准备区能看到目标职级和偏好领域。
- 没有简历/项目摘要时，会看到中性提示而不是错误样式。
- 有简历或项目摘要时，会看到“已接入档案上下文”的明确信号。

## 不做

- 不新增目标岗位字段。
- 不新增档案编辑能力。
- 不做 PDF 简历解析。
