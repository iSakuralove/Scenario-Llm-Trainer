# 面试舱分区加载态与错误态 PRD

## 目标

把面试舱启动台从“整页文案式状态”收口为更明确的分区加载态和分区错误态，至少覆盖：

- 启动台聚合数据加载骨架
- 历史记录加载骨架
- 启动台接口失败时的分区降级提示
- 历史记录接口失败时不影响其他面板

本任务只改 `InterviewsPage` 与 smoke，不新增接口。

## 已确认事实

- 当前页面已经有：
  - launchpad 接口失败时回退兼容轨道
  - history 接口失败时显示一条错误文案
- 但还没有：
  - 顶部状态 / 推荐区 / 覆盖区 / 轨道区的加载骨架
  - 历史区的加载骨架
  - 更明确的分区错误态标识

## 需求

1. 分区加载态
   - 启动台接口请求中时，状态区、推荐区、覆盖区、轨道区显示骨架或占位，而不是只靠整页已渲染内容。
   - 历史接口请求中时，历史区显示独立骨架。

2. 分区错误态
   - Launchpad 接口失败时：
     - 页面仍回退兼容轨道
     - 同时要有明确的分区提示，表明这是接口异常后的兼容模式
   - History 接口失败时：
     - 只影响历史区
     - 不能影响启动台其他区域渲染和交互

3. 验证
   - smoke 至少验证：
     - 延迟响应时可看到加载骨架
     - history 失败时页面仍可渲染启动台主区域

## 验收标准

- `/interviews` 在 launchpad 延迟响应时能看到加载骨架。
- `/interviews` 在 history 接口失败时仍能看到启动台主区域。
- Launchpad 接口失败时页面仍能进入兼容轨道，并显示明确提示。

## 不做

- 不引入全局 skeleton 组件库。
- 不改后端接口结构。
