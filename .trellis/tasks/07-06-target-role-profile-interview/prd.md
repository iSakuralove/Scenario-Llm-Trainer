# 目标岗位字段接入面试舱 PRD

## 目标

补齐 PRD 里“目标岗位”这一项，把它从个人档案接入到面试舱准备区展示。

首版范围：

- 用户 profile 新增 `target_role`
- 个人档案页可编辑
- 面试舱准备区可展示

## 已确认事实

- 当前 profile 已有：
  - `target_level`
  - `preferred_domains`
  - `resume_summary`
  - `project_summary`
- 当前 PRD 明确把“目标岗位”列在准备页增强项里。
- 当前页面只能展示目标职级和偏好领域，还没有单独的岗位字段。

## 需求

1. 数据结构
   - `UserProfile` 增加 `target_role`
   - 前后端 JSON 契约同步

2. 个人档案
   - 个人档案页新增可编辑的目标岗位输入

3. 面试舱准备区
   - 准备区显式展示 `目标岗位`
   - 若为空，显示中性占位“待补充”

## 验收标准

- 更新个人档案时能保存 `target_role`
- 重新进入面试舱能看到当前目标岗位

## 不做

- 不做岗位推荐算法
- 不做岗位字段和偏好领域的自动映射
