# 独立 AI Mentor 页面 PRD

## 目标

补齐当前仓库里仍然缺失的“独立 AI Mentor 页面”，提供一个单独路由，让用户不必只从仪表盘或报告碎片里看建议，而能集中查看：

- 当前综合诊断
- 主要风险提醒
- 下一步行动建议
- 知识覆盖与待补方向

首版优先复用当前已有接口，不等待新的后端 Mentor 专用接口。

## 已确认事实

- 当前仓库已经有：
  - `/dashboard`
  - `/interviews`
  - `/profile`
  - 面试报告知识点覆盖
  - 仪表盘面试专项建议
- 当前仓库还没有：
  - `/mentor` 路由
  - 独立 Mentor 页面
- 参考仓库已有 `Mentor.vue`，包含：
  - 综合诊断
  - 风险预警
  - 建议行动

## 需求

1. 路由与入口
   - 新增 `/mentor` 页面。
   - 侧边导航提供入口。

2. 数据来源
   - 首版可复用现有接口：
     - `GET /users/me/dashboard`
     - `GET /interviews/launchpad`
     - `GET /users/me/history`
   - 不强制新增后端 Mentor 专用接口。

3. 页面内容
   - 综合诊断：
     - 基于学习计划摘要、薄弱领域、目标画像生成高层概览
   - 风险预警：
     - 如知识覆盖率偏低、档案为空、启动台处于兼容模式/降级模式等
   - 建议行动：
     - 复用当前学习计划/面试专项建议
   - 知识覆盖：
     - 复用 launchpad 的 `coverage_stats`

4. 空态与错误态
   - 任一数据请求失败时，要给出明确提示。
   - 若还没有面试样本，也要能渲染出空态，不报错。

## 验收标准

- `/mentor` 可访问且渲染成功。
- 页面能看到综合诊断、风险预警、建议行动、知识覆盖至少四个区块。
- 无历史面试样本时，页面仍能渲染，不崩溃。

## 不做

- 不强制新增 LLM 驱动的后端 Mentor 洞察接口。
- 不接用户自定义 Provider 配置。
- 不做 PDF 简历解析。
