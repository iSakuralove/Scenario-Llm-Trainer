# 运营动作面板移动端与浏览器冒烟验证 PRD

## 目标

在本机真实 Chrome 管理员会话中验证题库运营动作链路已具备可用的产品闭环，并检查窄屏、长文本、空状态和错误提示是否清晰。

## 已确认事实

- 后端已实现运营动作列表、候选生成与保存、详情读取、状态流转和历史记录。
- 前端已实现动作过滤、详情面板、证据快照、atom 当前状态、套用组合、打开 atom、单 atom 重建与状态按钮。
- 后端专项测试、Go 全量、前端 lint/build 已通过。
- 当前没有运营动作专项浏览器用例，本任务以真实浏览器 HITL 验证为主。

## 验证范围

1. 管理员进入 `/interview-bank`，运营动作区域能够加载，不出现错误边界或明显控制台异常。
2. 列表与过滤：
   - 状态、类型、优先级、来源过滤可操作。
   - 无结果时显示明确空状态。
3. 动作详情：
   - 展示标题、类型、状态、优先级、来源、原因和更新时间。
   - compact evidence 可读，长文本正常换行。
   - 有 atom 时展示当前状态、索引状态、版本和 stale 提示。
4. 治理入口复用：
   - 组合目标可套用到题库筛选和检索预览。
   - atom 动作可打开现有原子详情。
   - `rebuild_index + atom_id` 可调用现有单 atom 重建入口。
5. 状态闭环：
   - 可切换处理中、观察中、已解决、已忽略和已重开。
   - 解决/忽略未填备注时前端阻止提交。
   - 成功更新后详情状态和历史列表同步刷新。
6. 响应式：
   - 桌面常用宽度正常。
   - 390px 窄屏无页面级横向溢出，按钮、过滤器、证据和历史仍可操作。

## 数据与安全约束

- 优先复用本地已有运营动作。
- 若本地没有动作，可创建明确标记为浏览器冒烟的演示动作。
- 不删除 atom、动作或其他业务数据。
- 不执行发布、支付、账号设置等无关操作。
- 重建索引和状态更新只在本地演示环境执行。

## 验收标准

- 核心操作链路全部可完成，且没有阻断性页面错误。
- 解决/忽略备注校验生效，状态历史按新到旧展示。
- stale、空状态和长文本表达清晰。
- 390px 窄屏无明显横向溢出或无法点击的主要操作。
- 发现的产品或布局问题已修复并重新验证；如无问题，记录验证结果和已知限制。

## 不做

- 不新增业务接口或数据库结构。
- 不扩大到面试舱、Mentor 或个人档案页面。
- 不为了验证而新增长期维护成本较高的完整 E2E 套件。
