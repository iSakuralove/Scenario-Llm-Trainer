# 面试舱目标画像与档案提示

## 目标

把面试舱准备区里“个人档案”的参与方式显式展示出来，让用户知道系统当前会参考哪些目标画像信息，并在缺少简历/项目摘要时看到中性提示。

## 修改范围

- `InterviewsPage.tsx` 在准备区新增“目标画像”块。
- `InterviewsPage.css` 增加目标画像块和档案上下文 chips 样式。
- `frontend-smoke.mjs` 增加目标职级和中性提示断言。

## 核心实现

- 目标画像块显式展示：
  - `目标职级`
  - `偏好领域`
- 当存在 `resume_summary` 或 `project_summary` 时：
  - 显示 `已接入简历摘要` / `已接入项目摘要` 信号
  - 说明本场追问会参考这些档案内容
- 当两者都为空时：
  - 显示中性提示 `补充后更精准`
  - 同时明确说明不会阻断开始训练
- 不新增后端字段，也不改变已有“准备备注”的可编辑行为。

## 影响范围

- 只增强前端准备区信息密度。
- 不改档案编辑页，不改会话创建接口。

## 验证方式

- `npm --prefix frontend run lint`
- `npm --prefix frontend run build`
- `npm --prefix frontend run smoke`

## 已知限制

- 当前系统没有独立“目标岗位名称”字段，所以准备区仍以 `目标职级 + 偏好领域` 组合表达目标岗位画像。
- 当前档案上下文块只做可见性提示，不单独展开简历/项目摘要全文。
