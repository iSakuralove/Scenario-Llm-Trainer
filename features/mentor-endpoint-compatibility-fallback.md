# AI Mentor 接口兼容降级

## 目标

当前端已包含 AI Mentor 页面、但旧后端尚未提供 `/users/me/mentor` 时，避免整页显示 `not found`。

## 修改范围

- Mentor 页面识别接口 404，并切换为只读兼容快照。
- 兼容快照提供明确说明、训练入口和档案入口。

## 核心实现

- 仅当错误消息为 `not found` 时降级；鉴权失败、网络错误和服务器错误仍进入原错误面板。
- 兼容模式不伪造优势、弱项、覆盖率或完成次数，相关统计保持零值。

## 影响范围

- 不修改后端接口或数据库。
- 新后端接口可用后仍优先展示真实聚合数据。

## 验证方式

- `npm --prefix frontend run lint`
- `npm --prefix frontend run build`
- 真实浏览器访问 `/mentor`，旧 API 返回 404 时页面显示兼容模式而非错误页。

## 已知限制

- 兼容模式无法生成真实诊断，需要部署包含 Mentor 接口的新后端后才能展示聚合结果。
