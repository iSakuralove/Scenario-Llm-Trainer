# 个人档案密码安全区域布局优化

## 目标

解决密码输入、更新按钮和说明文字挤在同一行的问题，提升可读性和操作层级。

## 修改范围

- 密码安全区域改为纵向表单。
- 增加说明文案、完整宽度输入框和独立提示区。
- 更新个人档案 E2E 选择器，避免新增密码输入框影响偏好设置测试。

## 核心实现

- 使用 `profile-security-panel`、`profile-security-form` 和 `profile-security-note` 独立控制布局。
- 更新密码按钮占满内容宽度，提示文字在独立浅色区域换行显示。

## 影响范围

- 仅影响个人档案视觉布局，不修改密码接口或认证逻辑。

## 验证方式

- `npm --prefix frontend run lint`
- `npm --prefix frontend run build`
- 真实浏览器确认密码安全区域文字分组和间距正常。

## 已知限制

- 未执行真实改密操作，避免修改当前演示账号密码。
