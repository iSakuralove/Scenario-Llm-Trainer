# 面试舱推荐卡开始训练主按钮

## 目标

把面试舱推荐卡补成完整的“双动作”结构：

- 主按钮：开始训练
- 次按钮：查看覆盖

## 修改范围

- `InterviewsPage.tsx` 复用现有启动逻辑，支持从推荐卡直接发起会话创建。
- 推荐卡动作区增加 `开始训练` 主按钮。
- `InterviewsPage.css` 调整推荐卡动作区布局。
- `frontend-smoke.mjs` 对 launchpad 和创建会话接口做定向 mock，验证推荐卡主按钮能进入会话路由。

## 核心实现

- 没有新造第二套创建会话逻辑，而是把现有 `start()` 扩展为可接收指定推荐轨道。
- 点击推荐卡 `开始训练` 时：
  - 先把当前选中轨道切到该推荐项
  - 再复用页面已有的难度倾向、考察重点和准备备注发起会话创建
- 推荐卡主体点击仍然保留“只选中轨道”的轻交互，不和主按钮冲突。
- 启动中状态复用现有 `isStarting`，避免重复创建会话。

## 影响范围

- 不改后端推荐来源。
- 不改会话创建接口结构。
- 不影响页面顶部和开放轨道区已有的开始面试按钮。

## 验证方式

- `npm --prefix frontend run lint`
- `npm --prefix frontend run build`
- `npm --prefix frontend run smoke`

## 已知限制

- 当前推荐卡的 `开始训练` 仍复用页面全局的准备参数，而不是为每张推荐卡维护独立配置。
- smoke 为了稳定验证使用了定向 mock，不代表真实后端一定返回对应推荐卡，但能验证前端交互闭环本身。
